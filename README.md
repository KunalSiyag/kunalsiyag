## ⚡ Live Production Systems

<details open>
<summary><b>🔒 ProtectedShare — Secure Ephemeral Data & File Sharing</b></summary>
<br/>

> **Link:** [protectedshare.me](https://protectedshare.me)

**Problem:** Standard cloud sharing retains data permanently, compromising privacy and leaving digital footprints susceptible to leaks.
**System Architecture:**
- Fully client-side zero-knowledge encryption architecture.
- Ephemeral backend engine with automated end-of-life (TTL) purge routines.
- Lightweight, high-throughput transmission pipeline ensuring minimal operational overhead.

**Engineering Focus:** Secure cryptographic key management, automated data expiration systems, zero-trust storage constraints.
</details>

<details open>
<summary><b>💳 ProUpiQr — Dynamic B2B UPI Payment Infrastructure</b></summary>
<br/>

> **Link:** [proupiqr.in](https://proupiqr.in)

**Problem:** Static QR payment systems lack tracking capabilities, while enterprise payment gateway APIs impose restrictive transaction cuts on small-to-midscale operations.
**System Architecture:**
- Real-time dynamic UPI string generation payload mapped directly into low-footprint scannable vectors.
- Instant, zero-intermediary transaction confirmation infrastructure processing raw intents straight to peer endpoints.
- Lightweight abstraction layer allowing direct integration for multi-tenant business billing ecosystems.

**Engineering Focus:** Low-latency payload serialization, high-concurrency API performance, zero-fee payment pipeline automation.
</details>
