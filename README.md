I like projects you can *watch*: a camera that chases a cursor, a city that argues with itself, a checkout that falls over under load. Lately that means Rust on Linux graphics, simulations run by AI agents, and tooling for the agents themselves. I write up the interesting parts on DEV and Medium.

### currently

- Building **SwarmCorp**, mission control for fleets of coding agents: one live map of every session and subagent, with a receipt for each run
- Shipping **HyperGSR** v1.2 to crates.io and npm, and writing about reading the cursor straight off the GPU
- Contributing upstream to **openzim/mwoffliner** and **Apache Impala**
